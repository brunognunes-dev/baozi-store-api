# Baozi Store API

API REST desenvolvida para a disciplina de Desenvolvimento Web Back-End.

## Tecnologias

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Postman

## Entidades

- Cliente
- Produto
- Pedido

## Endpoints

### Clientes

- POST /clientes
- GET /clientes
- GET /clientes/{id}
- DELETE /clientes/{id}

### Produtos

- POST /produtos
- GET /produtos
- GET /produtos/{id}
- DELETE /produtos/{id}

### Pedidos

- POST /pedidos
- GET /pedidos
- GET /pedidos/{id}
- DELETE /pedidos/{id}
